📂 Struktur Monorepo E-learning SMA

🎯 Ringkasan Monorepo

Monorepo my-app dengan Turborepo + pnpm workspace untuk platform e-learning SMA kelas 10-12.

📱 apps/web

  • Next.js 14+ App Router
  • Halaman publik SEO-friendly
  • Dashboard siswa + guru
  • Zustand untuk state kuis
  • Tailwind CSS

⚡ apps/api

  • Hono framework
  • OpenAPI/Swagger di /docs
  • Services: XP, streak, mastery
  • Drizzle ORM + Postgres
  • Docker Compose

📦 packages/shared

  • Skema Zod
  • Types TypeScript
  • Kontrak materi, kuis, gamifikasi
  • Dipakai web + api

⚙️ packages/config

  • ESLint config
  • TypeScript config
  • Tailwind config
  • Shared tooling
⚠️ Aturan penting:
  • apps/web dan apps/api tidak boleh saling import kode
  • Komunikasi lewat HTTP + types dari packages/shared
  • packages/* tidak boleh import dari apps/*

🔗 Diagram Dependensi

Bagaimana paket-paket saling bergantung:

1
apps/web → packages/shared (import types & schema)
↓
2
apps/api → packages/shared (import types & schema)
↓
3
apps/web ⟷ apps/api (HTTP only, tidak ada code import)
↓
4
apps/api → Postgres (via Docker Compose)
✅ Prinsip dependensi:
  • packages/shared adalah sumber truth untuk kontrak data
  • Web dan API tidak boleh saling import, hanya komunikasi HTTP
  • packages/config hanya konfigurasi tooling, tanpa logik bisnis
  • packages/* tidak boleh import dari apps/*

🔄 Alur Data Gamifikasi

Contoh: siswa selesai kuis, sistem hitung XP, update streak & mastery.

1
Siswa jawab kuis di /kuis/[id]
↓
2
Zustand quiz-store simpan jawaban sementara
↓
3
POST /kuis/:id/submit kirim jawaban ke API
↓
4
API panggil services/xp.ts, streak.ts, mastery.ts
↓
5
Insert ke Postgres: xp_events, update streak, mastery
↓
6
Return hasil: { skor, xpGained, newLevel, streakDays }
↓
7
Dashboard GET /progres tampilkan update

⚡ Services logic

Service Fungsi Input Output
xp.ts Hitung XP & level per mapel userId, mapelId, jenis event XP gained, level baru
streak.ts Update streak harian userId, timestamp Jumlah hari streak, freeze sisa
mastery.ts Update status penguasaan topik userId, topikId, skor Status: belum/sedang/menguasai

🚀 Endpoints API

Dokumentasi lengkap tersedia di /docs (Swagger UI).

Method Path Fungsi Body/Query
GET /materi Daftar mapel & bab ?kelas=10
GET /materi/:topikId Detail topik (video, teks, contoh) -
GET /kuis/:kuisId Soal kuis (tanpa kunci jawaban) -
POST /kuis/:kuisId/submit Submit jawaban, dapat skor + XP + streak { jawaban: [...] }
GET /progres Ringkasan progres & mastery siswa ?userId=xxx
GET /gamifikasi/streak Status streak harian -
GET /gamifikasi/leaderboard Leaderboard kelas (opt-in) ?kelasId=xxx
POST /guru/materi Upload materi baru FormData (video/teks)
POST /guru/soal Buat soal kuis { pertanyaan, opsi, jawaban }

📝 Contoh response POST /kuis/:id/submit

{
  "skor": 85,
  "benar": 17,
  "salah": 3,
  "xpGained": 170,
  "newLevel": 5,
  "streakDays": 12,
  "mastery": {
    "topikId": "mtk-trigonometri",
    "status": "menguasai"
  }
}

🗄️ Skema Database

Postgres dengan Drizzle ORM. Tabel-tabel inti gamifikasi:

Tabel: xp_events

Kolom Tipe Keterangan
iduuidPrimary key
user_iduuidForeign key ke users
mapel_idtextID mata pelajaran
jenistextmateri_selesai | kuis_selesai | jawaban_benar | tryout
jumlahintJumlah XP yang didapat
created_attimestamptzWaktu event

Tabel: streak

Kolom Tipe Keterangan
user_iduuidPrimary key
hari_terakhirdateTanggal terakhir belajar
jumlah_hariintJumlah hari berturut-turut
freeze_sisaintSisa streak freeze (max 2)

Tabel: mastery

Kolom Tipe Keterangan
user_iduuidComposite key
topik_idtextComposite key
statustextbelum | sedang_belajar | menguasai
skor_terakhirnumeric(5,2)0-100
percobaanintJumlah kali mengerjakan

Tabel: badges

Kolom Tipe Keterangan
idtextPrimary key (slug)
namatextNama badge
deskripsitextSyarat dapat

Tabel: user_badges

Kolom Tipe Keterangan
user_iduuidComposite key
badge_idtextComposite key
earned_attimestamptzWaktu dapat badge

Tabel: leaderboard_weekly

Kolom Tipe Keterangan
minggudateComposite key (senin minggu itu)
user_iduuidComposite key
kelas_iduuidID kelas
xpintTotal XP minggu ini
💡 Tips: Tabel xp_events append-only (tidak pernah diupdate/delete) untuk audit trail. View materialized untuk leaderboard agar query cepat.
